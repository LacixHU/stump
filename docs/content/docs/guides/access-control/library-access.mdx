Access to libraries is an opt-in model. Only users who are explicitly included on a library can see it and its contents. The server owner always has access to every library and does not need to be added to the include list.

## Configure Inclusions

<Callout title="Permission required">
	This functionality is gated behind the `MANAGE_LIBRARY` and `READ_USERS` user permissions. To
	learn more about permissions, see the [permissions](/docs/guides/access-control/permissions)
	guide.
</Callout>

<Steps>

<Step>
### Navigate to the library settings

Navigate to the library you want to grant access to and click on the `Settings` tab.

</Step>

<Step>
### Select `Access Control` in the sidebar

The `Include users` section is located towards the bottom of the settings page. It contains a multi-select dropdown that allows you to select the users who may access the library.

</Step>

<Step>
### Select the user(s) to include

Use the multi-select dropdown to select the users who should have access to the library. You can select multiple users. The server owner is not listed and always retains access.

</Step>

<Step>
### Save your changes

Autosave is enabled, so any changes should take effect immediately. Users who are not included will no longer have access to the library or any content within it.

</Step>

</Steps>
